# Linux Networking & Cloud Infrastructure

## Objective
Deploy a Linux server on AWS EC2, configure secure access,
install Nginx and expose a web service.

## Technologies Used
- AWS EC2
- Amazon Linux
- Linux
- SSH
- Nginx
- AWS Security Groups
- Networking

## Implementation
1. Created an EC2 Linux server
2. Configured SSH access
3. Practiced Linux commands
4. Created users and groups
5. Configured file permissions
6. Installed Nginx
7. Configured HTTP access
8. Deployed a custom webpage
9. Tested connectivity

## Result
Successfully deployed a Linux server and hosted
a web page using Nginx.
